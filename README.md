# ☕ Coffee POS — Telegram-бот и Mini App для кофейни

Telegram-бот для кофейни: клиент оформляет заказ через Mini App (меню → корзина → время готовности → оплата), баристу приходит уведомление, а барист имеет веб-панель со списком заказов по времени готовности и обратным таймером.

## Возможности (MVP)

- 🤖 **Бот**: команда `/start` → открывает Mini App с меню.
- 🍽️ **Mini App клиента** (`/menu`):
  - Просмотр меню (категории, позиции, цены, описания).
  - Корзина: количество, удаление, итог.
  - Выбор способа оплаты: **карта** / **наличные**.
  - Выбор времени готовности: через 5 / 10 / 15 / 20 / 30 минут.
  - После отправки заказа (`tg.sendData`) бот получает данные и оформляет заказ.
- 🔔 **Уведомление баристу**: в Telegram-чат бариста — номер заказа, позиции, цена, способ оплаты, готовность.
- 📋 **Mini App бариста** (`/orders`):
  - Список активных заказов отсортирован по оставшемуся времени готовности.
  - У каждого заказа — **обратный таймер** (countdown до готовности/выдачи).
  - Кнопка «Выдать заказ» → заказ помечается готовым, клиенту отправляется уведомление.

## Технологии

- **Telegram Bot API**: [GrammY](https://grammy.js.org/) + TypeScript
- **Mini Apps**: Telegram Web Apps SDK (`telegram-web-app.js`)
- **База данных**: Prisma + SQLite (файл `dev.db`)
- **Сервер**: Express (webhook + статика Mini Apps + API)
- **Валидация конфигурации**: Zod

## Переменные окружения

Скопируйте `.env.example` → `.env`:

| Переменная | Обязательная | Описание |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен бота от BotFather |
| `DATABASE_URL` | ✅ | `file:./dev.db` для SQLite |
| `BARISTA_CHAT_IDS` | — | Chat ID чата/группы бариста через запятую |
| `MINI_APP_MENU_URL` | — | URL Mini App меню |
| `MINI_APP_ORDERS_URL` | — | URL Mini App бариста |
| `WEBHOOK_URL` | prod | URL для webhook |
| `WEBHOOK_SECRET` | prod | Секрет для webhook |
| `BARISTA_API_KEY` | — | API-ключ для `/api/orders` |
| `PORT` | — | Порт сервера (default 3000) |
| `MENU_URL` | — | URL меню (обновляется из меню кофейни) |

## Деплой

1. Создать бота через BotFather, включить **Bot API Web Apps**.
2. Установить webhook:
   ```
   https://api.telegram.org/bot<TOKEN>/setWebhook?url=<DOMAIN>/webhook&secret_token=<SECRET>
   ```
3. Указать Mini App URL в BotFather для кнопок.
4. Указать `BARISTA_CHAT_IDS` — id чата бариста.

## Как это работает

1. Клиент через Telegram открывает Mini App `/menu`, собирает заказ.
2. Выбирает время готовности (ETA) и оплату (карта/наличные).
3. `tg.sendData` → бот создаёт заказ в БД (номер, позиции, сумма, оплата, ETA, клиент — ник/username/телефон), отправляет уведомление баристу.
4. Барист открывает `/orders` → видит список отсортированный по ETA, со countdown.
5. По истечении ETA (или по кнопке) заказ помечается готовым → клиенту уведомление.
